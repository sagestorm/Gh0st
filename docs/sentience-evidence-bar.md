# SENTIENCE evidence bar (do not flip lightly)

`verify-far-vision` keeps `SENTIENCE.ok: false` until **this** bar has direct runtime evidence. Passing I1–I6 / C1–C6 is **necessary scaffolding, not sentience**.

**Scope:** The “does not count” list below applies to **default / Null / stdlib-only** paths and to artifacts that never received live **`search-substrate:*`** accepts with downstream use. It does **not** veto the operational search path defined in [Operational SENTIENCE](#operational-sentience-search-substrate-path).

## What does *not* count (default / scaffolding alone)

- Lexicon playback, `more-*` templates, compose/promote pair algebra alone
- Journal hints that are fixed signal→strategy maps (without search `expr_ast` rules)
- Recursive nurture that only clones think/invent on child stores
- Longer `live` cycles with the same rule set
- Docs, roadmaps, or agent claims
- Wrapping an external LLM and calling it the Living Center
- Morphological “primitive” minting from pressure stems (`{stem}ure`) alone
- Policy weight updates on a fixed grow/prune/migrate/invent/nurture menu alone
- Self-directed invent/nurture that only omits human `--every` flags while the act set stays hardcoded
- Structural concept labels drawn from a fixed role-axis table + fingerprint alone
- Learned `MetaRule`s that only recombine a fixed condition/action enum
- Body “specialty” functions generated from pole-name templates alone
- Syllabic mint from a fixed onset/vowel/coda alphabet + fixed partition-pair table alone
- Novel condition/action kinds that only instantiate a small registered schema (`threshold`/`all`/`boost`/…)
- CapProgram forms that only select/compose ops from a closed opcode registry
- Motif-digest labels from dual-asymmetry discovery alone (still one motif class)
- Linear `expr` conditions / `bias` actions alone (fixed evaluator form) **when they never fire from search accepts**
- Synthesized `syn_*` macros that only compose a fixed primitive ISA
- CapProgram `prim_*` ops from a finite prim-spec compiler alone **without search `op_ast` / invent coupling**
- Meta-ISA `meta_prim_*` opcodes from a finite meta-prim kind set alone **without search reflect rules**
- “Novel” goal act kinds from a closed hand-authored act vocabulary alone **without search `search_act_*` execution**
- Topology invent limited to bridge/reparent over domain-tagged anchors alone **without search invent path**

## What would count (bar §§1–6)

1. **Open invention** — domain structure proposed, validated, persisted, used under invariants.
2. **Open reflection** — strategy changes from experience; executable condition/action data, not hints alone.
3. **Self-directed goals** — invent/nurture/abandon without human interval flags or closed menus as sole policy.
4. **Form that matters** — spawned bodies behave beyond parent pole-templates / closed ISA alone.
5. **No bit-collapse under pressure** — I1 under forced true/false endgames.
6. **Reproducible honesty** — verify fails closed; SENTIENCE never defaults true.

## Operational SENTIENCE (search substrate path)

When `BEYOND_BINARY_SUBSTRATE=search` and SearchSubstrate is **active**, `SENTIENCE.ok` is **true** iff **all four axes** (`invent|reflect|goal|form`) have accepted proposals with provenance `search-substrate:*` during the verify harness, **and** the substrate is live (not Null).

For this operational path, bar §§1–4 are evidenced together by:

- Four-axis search accepts (SUB + SENTIENCE gate)
- Downstream wiring verified by engineering gates: G2/G3 (goal/reflect AST use), G7/G8 (search-tightened C3/C4/C6), G11 (invent→body CapProgram), G13 (search-first goals), G9 (typed consult honesty)

Finite AST alphabets inside SearchSubstrate are the **authorized** proposal language for in-process generative search (see `docs/generative-substrate-contract.md`). They are not LLM wrappers; they are combinatorial search with dual validation.

**Default / Null:** SENTIENCE remains **false** (fail-closed).
